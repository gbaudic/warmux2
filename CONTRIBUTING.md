# How to contribute

I'm really glad you're reading this, because we need volunteer developers to help this project come to fruition.

Everything happens on GitHub. Check out the [open issues](https://github.com/gbaudic/warmux2/issues), see the [wiki](https://github.com/gbaudic/warmux2/wiki).

## Testing

Everything is manual for the moment...

## Submitting changes

Please send a [GitHub Pull Request](https://github.com/gbaudic/warmux2/pull/new/master) with a clear list of what you've done (read more about [pull requests](http://help.github.com/pull-requests/)). Please follow our coding conventions (below) and make sure all of your commits are atomic (one feature per commit).

Always write a clear log message for your commits. One-line messages are fine for small changes, but bigger changes should look like this:

    $ git commit -m "[topic] A brief summary of the commit
    > 
    > A paragraph describing what changed and its impact."

Also prefix it, whether you are \[fix\]ing a bug, adding a \[feat\]ure, doing some \[cleanup\], improving the \[security\]... If in doubt, ask in the PR and rename your commit as requested.

## Coding conventions

Start reading our code and you'll get the hang of it. We optimize for readability. Remember that no matter which project you are working on, we code for other people, not compilers, computers, or AI agents.

## I am not a developer, can I still help?

Sure! While the project is already quite mature, contributions outside of code are also necessary (check out the list of past authors if you have doubts!). The following areas are worthy of contributions:

  - Documentation
  - Translations
  - Artwork
    - New maps
    - New teams
    - New music and sounds
