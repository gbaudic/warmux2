# Warmux

[![Quality Gate Status](https://sonarcloud.io/api/project_badges/measure?project=gbaudic_warmux2&metric=alert_status)](https://sonarcloud.io/summary/new_code?id=gbaudic_warmux2) [![pipeline](https://github.com/gbaudic/warmux2/actions/workflows/pipeline.yml/badge.svg)](https://github.com/gbaudic/warmux2/actions/workflows/pipeline.yml)

warmux was a worms free opensource clone project. 

![logo](https://raw.githubusercontent.com/gbaudic/warmux2/master/logo.png)

The code has been published by one of the former authors, yeKcim, [here](https://github.com/yekcim/warmux). Unfortunately, the original SVN repository was hosted on GNA, a service that stopped operating in 2017... so most of the history has been lost. 

The present repository is an attempt to revive it, which means to make it build again and use more recent dependency versions. The former website is down ([wayback machine](http://web.archive.org/web/20120304160644/http://www.wormux.org/phpboost/news/news.php)) but its wiki has been restored in the wiki of the present project and will be updated as needed. 

**Please note that this project is considered as in maintenance mode only.** Contributions are welcome but new features are not likely to be accepted, even if they appear in the roadmap artworks. 

## Why warmux "2"?

Because "warmux" was already used on my account by the fork of yeKcim's repo ;-). However, this is the same codebase. The only difference in the commit history is that I replayed the old versions so the "old" folder is missing: its contents can instead be found in the Releases of the current project.
